# Absence types — transcribed from Skello settings

Source: 7 screenshots received 2026-11-16, covering all four Skello sections.
The screenshots are scrolled captures, so a row hidden between two of them
cannot be excluded.

Columns, as named in Skello:
- **Active** — toggle on. Read from the toggle position and the darker label;
  to be confirmed.
- **Acquis.** — permet l'acquisition de congés.
- **Indem.** — indemnité compensatrice.
- **Employé** — peut être demandée par l'employé. "—" means no checkbox shown.
- **HS** — déclenche des heures supplémentaires: Majorées or Normales.

Congé naissance, Congé payé, RTT, Congé maternité, Congé paternité, Congé
supplémentaire de naissance, Congé sans solde, Récupération.
